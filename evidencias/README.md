# Evidências do projeto

Esta pasta será utilizada para registrar evidências relevantes do processo de desenvolvimento, como capturas de tela ou registros das etapas de criação, geração e edição do podcast.

As evidências serão adicionadas somente quando cada etapa for efetivamente realizada.

## Organização prevista

- criação e revisão do roteiro;
- utilização das ferramentas de IA;
- geração das vozes;
- edição do áudio;
- resultado final.
